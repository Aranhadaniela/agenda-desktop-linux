# Alterações

## 0.1.0 — em preparação, ainda não publicada

- Core Python com modelo de evento, serviço de consulta e ordenação por instante.
- Provider Evolution Data Server com descoberta e seleção de calendários habilitados e expansão de instâncias pelo EDS.
- CLI com seleção de fonte, janela em dias e destino JSON configuráveis.
- Exportação atômica com permissão 0600, mantendo o contrato JSON existente.
- Tratamento de fusos e datas de dia inteiro com testes sintéticos.
- 15 testes automatizados e documentação de segurança, dependências e publicação.
